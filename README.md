# Real Estate Management

A web-based platform for managing real estate operations, including apartments, owners, contracts, expenses, permissions, and rental reports. The system provides an intuitive interface for property managers to handle day-to-day tasks efficiently.

## Features

- Apartment, owner, and contract management
- Expense and outlay tracking
- Rental payment and delivery reports
- OTP-based authentication for secure access
- User-friendly dashboards and reports

## Project Structure

- HTML files for each feature (e.g., `add-apartment.html`, `all-contracts.html`)
- Central JavaScript logic (e.g., `script.js`, `otp.js`)
- CSS for styling (`styles.css`, `otp.css`, etc.)
- Asset folders: `images/`, `fonts/`, `css/`, `js/`

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MOHAMEDHAMED1S/Real-estate-management.git
   ```
2. **Open the project folder in your browser or a local server.**
   - You can use VS Code Live Server or any static server.

3. **Navigate to `index.html` to start using the system.**

## OTP Authentication

- Enter your phone number (without country code).
- Select your country code from the dropdown.
- Enter the OTP sent to your phone.
- The system supports both Arabic and English numerals.

## Customization

- Update HTML files to add or modify features.
- Edit CSS files for custom styles.
- Extend JavaScript files for additional logic.
